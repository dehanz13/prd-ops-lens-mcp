# Sprint notes

Create `sprint-N.md` at the end of each one-week iteration. Use real issue and
PR links, not estimates or work that has not merged into `develop`.

## Note format

- Goal: the planned outcome from the Project README.
- Done: linked stories and reviewed PRs merged during this sprint.
- Velocity: sum of the Size points for those Done stories.
- Slipped: story links, why they slipped, and their next status.
- Improvement: one concrete change to try in the next sprint.
